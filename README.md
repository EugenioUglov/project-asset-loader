# Project Asset Loader - Tests

This repository contains tests and usage examples for the **`project-asset-loader`** package.

## Installation

Install the package via npm:

```bash
npm install project-asset-loader

Running the Tests
The tests are structured as static HTML pages to verify package functionality across different module environments (ESM and UMD).

To run the tests locally:
1. Start a local development server (such as Live Server in VS Code) from the project root.
2. Open the desired test page in your browser:
    * ESM Test: Test ESM/index.html
    * UMD Test: Test UMD/index.html
